# MyMoney

אפליקציית ווב (PWA) למעקב אחרי תשלומים קבועים, הכנסות ומשמרות.
כתובת: https://zagurifitness.github.io/Money/

הנתונים נשמרים ב-Firebase תחת users/{uid}/money_* (או במכשיר בלבד כשלא מחוברים). אין נתונים אישיים בריפו.

דוח שנתי: `report.html` (https://zagurifitness.github.io/Money/report.html). מדריך מילוי לטופס 1301 לעוסק פטור שהוא גם שכיר: הכנסות, הוצאות, זיכויים, הערכת החזר, מפת שדות ורשימת מסמכים. נשמר תחת users/{uid}/money_tax.
